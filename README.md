# Civic-Chain Product Explainer Gallery

Review build that houses seven product explainers behind one shared top menu.
Open `index.html` (or deploy this folder statically) and pick an explainer from the menu.

| Explainer | Format | Best audience |
|---|---|---|
| Follow the Dollar | Follow-the-dollar narrative | Councils, residents, sales demos |
| Product Flow | Service blueprint | Product, design & ops teams |
| Product Overlap | Venn / overlap diagram | Slide openers, quick pitches |
| Platform Stack | Layer cake / stack | Investors, technical buyers |
| Capability Map | Comparison matrix | Procurement officers |
| Persona Journeys | Persona journey map | Sales, marketing |
| The 3 a.m. Fuel Charge | Storyboard / comic strip | Public-facing pages, town meetings |
